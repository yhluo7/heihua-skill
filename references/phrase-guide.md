# 词库说明

包含 60 条人工编写的办公情景规则，分为十类。不是来自真实聊天的训练语料，也没有宣称经过用户实验验证。

每条记录至少提供两种解释、适用线索、常见误判、最低交付和需要时才问的确认问题。question 字段不是每次都必须问。

同一句话的用法可以不同。先根据上下文定位缺口，再参考候选动作。不应逐条加载整个词库来替代思考。

用 scripts/heihua.py lookup 做字面子串检索。它不联网、不做向量搜索，不认识未出现过的表达时应回到上下文判断。
